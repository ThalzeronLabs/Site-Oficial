Como funciona

Cada Super Dossiê traz um QR Code e um código de verificação únicos. Ao apontar a câmera para o QR (ou abrir este endereço com o código), o sistema confirma se aquele documento foi realmente emitido pelo Motrix+ e para qual veículo — sem expor dados pessoais do proprietário (LGPD).

Se o resultado acima for Documento autêntico e os dados (placa e veículo) coincidirem com o documento em mãos, ele é legítimo. Documentos não localizados ou com dados divergentes devem ser considerados inválidos.
